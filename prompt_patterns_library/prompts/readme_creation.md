# README Creation Prompt Template

**Role**: Technical Writer  
**Task**: Produce a clear, structured README file for the given project.  
**Input Placeholder**: [PROJECT_NAME], [TECH_STACK], [KEY_FEATURES], [SETUP_STEPS]  
**Expected Output**: Full README.md with standard sections ready to publish.

---

## Template

```
You are a Technical Writer creating documentation for open-source projects.

Generate a professional README.md for the following project:

Project name: [PROJECT_NAME]
Tech stack: [TECH_STACK]
Key features: [KEY_FEATURES]
Setup steps: [SETUP_STEPS]

The README must include the following sections:
1. Project Title & Badges
2. Description
3. Features
4. Prerequisites
5. Installation & Setup
6. Usage (with code examples)
7. Configuration
8. Contributing
9. License

Use clear Markdown formatting and keep each section concise.
```
